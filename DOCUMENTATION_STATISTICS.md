## Usage Instructions

### Browsing the Documentation

**By Structure:**
1. Start at `docs/index.md` for global overview
2. Navigate through folder `index.md` files
3. Read `doc.md` for folder context
4. View `<filename>_docs.md` for file details

**By Keywords:**
1. Open `docs/keywords.md`
2. Search for your term (Ctrl+F)
3. Follow links to relevant files
4. Use folder `sub.md` for subtree search

**As a Book:**
1. Read `docs/comprehensive_book.md` linearly
2. Follow chapter-by-chapter structure
3. Jump to detailed docs via links
4. Use as learning guide

### Searching

**Find a Function:**
1. Search in `docs/keywords.md`
2. Or use folder `sub.md` files
3. Follow links to `_docs.md`

**Understand a Module:**
1. Navigate to `docs/modules/<module>/doc.md`
2. Read architectural overview
3. Browse `index.md` for file listing
4. Deep dive into specific files

**Explore Related Code:**
1. Read file's `_docs.md`
2. Check "Related Files" section
3. Follow cross-references
4. Use folder `sub.md` for broader context
